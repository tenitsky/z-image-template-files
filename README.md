# Z-Image Turbo: RunPod ComfyUI template

> 📖 **Step-by-step guide:** [Z-Image Turbo on RunPod: the quickest way to run it in ComfyUI](https://tenitsky.com/guides/z-image-turbo-runpod/) · more free templates and ComfyUI guides at [tenitsky.com](https://tenitsky.com/)

Template files that set up **Z-Image Turbo** in ComfyUI on RunPod: the model, text
encoder and VAE, a set of custom nodes and a LoRA.

- [`setup.sh`](setup.sh): downloads the Z-Image Turbo weights and installs everything on first boot
- [`custom_nodes/`](custom_nodes): ComfyUI-Manager, KJNodes, Civicomfy, Prompt Cycler and more
- [`lora/`](lora): the Casual 3D LoRA for Z-Image Turbo
